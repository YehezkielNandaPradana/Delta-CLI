◆ Installation

Get Started in Seconds

Delta runs on Python 3.11+ with zero external dependencies for basic operation. Enhanced features available with optional packages.

1

Install via pip

pip install delta-security

2

Enhanced UI (recommended)

pip install delta-security[all]

3

Start Delta

delta or python -m delta

4

Configure AI Provider

On first run, Delta prompts you to configure an LLM provider. Ollama (local) works out of the box with no API key needed.

1

Clone the repository

git clone https://github.com/hackerai/delta.git

2

Install in development mode

cd delta && pip install -e .

3

Run Delta

delta

1

Pull the image

docker pull hackerai/delta:latest

2

Run Delta

docker run -it --rm hackerai/delta delta

3

With custom config

docker run -it --rm -v ~/.delta:/root/.delta hackerai/delta delta
